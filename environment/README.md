# Supplied reference files

`idm_controller.py` and `6e68_map.yaml` are byte-for-byte local copies of the supplied course Shared Environment files. They allow the historical review checker and a standalone repository to use the same reference without relying on another course folder.

The reference IDM uses the intended approaching-speed sign. Its presence does not establish the exact source revision deployed during the original tests. The route map does not explicitly establish a physical coordinate scale. Original attribution is retained; no new license is assigned to these course materials.
