# Review and verification records

- `review_notes.md`: original findings, fixed-results constraint and report revision status.
- `historical_verification_results.json`: retained numerical evidence from the original review.
- `report_revision_checks.json`: the original report-only revision snapshot before repository organization.
- `organization_manifest.json`: old-to-new paths and the removed redundant HTML alias.
- `report_build_checks.json`: current report-build input hashes and descriptive summaries.
- `source_manifest.json`: portable hashes for original scientific and archived evidence.
- `publication_checks.json`: publication-time preservation, tests and standalone-clone verification.

Original snapshots retain their source paths and timestamps. Resolve renamed paths through the organization manifest rather than restoring the old folder layout. Neither report building nor the read-only tests refits a model or replaces recorded experimental outcomes.
