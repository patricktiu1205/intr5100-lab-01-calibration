# Lab 01 report

Use [the PDF](lab_01_report.pdf) for reading and [the HTML version](lab_01_report.html) for a browser view. The [LaTeX source](source/main.tex) and descriptive figures are in `source/`. The supplied report template is retained alongside the source; older figure assets are in `archive/figures/`.

From the repository root, activate `intr5100` and run `PYTHONDONTWRITEBYTECODE=1 python src/build_report.py`. This rebuilds the report from the saved records and compiles it with Tectonic, without fitting or simulating. Current verification is in `../review/report_build_checks.json`.

The report describes fixed experimental results and explicitly labels the historical model-fit limitations. It does not introduce a corrected fit, new physical test or submission-status claim.
